Kurulum

Kaynaktan derleyin

JDK 17+ ve Android SDK Platform 35 gerekir. Release derlemesi kendi imzalama anahtarınızı ister; depoda keystore yoktur.

git clone https://github.com/talatozunal/AuroraTV-Android.git
cd AuroraTV-Android

# Android SDK yolunu tanımlayın
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties

./gradlew assembleDebug
# çıktı
app/build/outputs/apk/debug/app-debug.apk

# cihaza yükle
adb install -r app/build/outputs/apk/debug/app-debug.apk
