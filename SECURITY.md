# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private vulnerability reporting on this repository
(**Security → Report a vulnerability**) or email
`talatozunal@users.noreply.github.com`.

Please include:

- affected version and Android version,
- steps to reproduce,
- impact and any proof of concept,
- whether the issue also affects a release build.

The first response is targeted within 72 hours. Confirmed issues are fixed in a patch release
and credited unless you prefer to stay anonymous.

## Scope

In scope: the Android app, its parsers, local storage, playback service, child-profile PIN
handling and any code that processes untrusted playlist or EPG input.

Out of scope: the legality or availability of third-party streams, and issues that require a
rooted device or a modified APK.
