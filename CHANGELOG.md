## [1.0.0] — 2026-11-12

### Added

- Native Android IPTV client built with Kotlin, Jetpack Compose and Media3.
- M3U URL, local M3U file and Xtream Codes sources with optional XMLTV EPG.
- 7-day EPG with programme details, reminders and catch-up links.
- Live TV, movies and series browsing with favourites.
- 2- and 4-stream multi-screen mode with per-tile audio control.
- On-device smart search with Turkish character normalisation and fuzzy matching.
- Profiles, child mode with a 4-digit PIN and age-based content filtering.
- Background audio, picture-in-picture, external player support and TV/D-pad navigation.
- Five interface languages: Turkish, English, German, French and Italian.
- Empty first launch: no bundled playlists, channels, movies or series.
